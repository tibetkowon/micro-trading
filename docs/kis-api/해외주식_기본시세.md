# [해외주식] 기본시세 API 명세

> **Domain**: 실전 `https://openapi.koreainvestment.com:9443` / 모의 `:29443`
> **공통 헤더**: `content-type: application/json; charset=utf-8`, `authorization: Bearer {token}`, `appkey`, `appsecret`, `tr_id`

---

## 1. 현재체결가

- **Method/URL**: `GET /uapi/overseas-price/v1/quotations/price`
- **TR_ID**: `HHDFS00000300` (모의 지원)

> **⚠️ REST API는 무료 지연 시세만 제공 — 실시간은 WebSocket `HDFSCNT0` 사용**

### 요청 Query

| Element | Required | 설명 |
|---------|----------|------|
| AUTH | Y | 공백 |
| EXCD | Y | 거래소코드 — `NYS`/`NAS`/`AMS`/`HKS`/`TSE`/`SHS`/`SZS` |
| SYMB | Y | 종목코드 (예: `AAPL`, `TSLA`) |

### 응답 (output) 주요 필드

| Element | 설명 |
|---------|------|
| last | 현재가 |
| base | 전일종가 |
| diff | 전일대비 |
| rate | 등락율 |
| tvol | 거래량 |
| tamt | 거래대금 |
| zdiv | 소수점자리수 |
| open | 시가 |
| high | 고가 |
| low | 저가 |
| valx | 시가총액 |
| e_ordyn | 주문가능여부 |

## 2. 분봉 조회

- **Method/URL**: `GET /uapi/overseas-price/v1/quotations/inquire-time-itemchartprice`
- **TR_ID**: `HHDFS76950200` (**모의 미지원**)

### 요청 Query

| Element | Required | 설명 |
|---------|----------|------|
| AUTH | Y | 공백 |
| EXCD | Y | 거래소코드 |
| SYMB | Y | 종목코드 |
| NMIN | Y | 분단위 (`1`, `2`, `3`, `5`, `10`, `15`, `30`, `60`) |
| PINC | Y | 전일포함여부 `1`:포함, `0`:미포함 |
| NEXT | Y | 다음페이지 `0`:첫페이지 |
| NREC | Y | 조회건수 (최대 `120`) |
| FILL | Y | `0` |
| KEYB | Y | 공백 |

### 응답 (output2 — 분봉 배열)

| Element | 설명 |
|---------|------|
| kymd | 일자 (YYYYMMDD) |
| khms | 시간 (HHMMSS) |
| open | 시가 |
| high | 고가 |
| low | 저가 |
| last | 종가 |
| evol | 거래량 |
| eamt | 거래대금 |

---

## 3. 기간별시세 (일봉)

- **Method/URL**: `GET /uapi/overseas-price/v1/quotations/dailyprice`
- **TR_ID**: `HHDFS76240000`

### 요청 Query

| Element | Required | 설명 |
|---------|----------|------|
| AUTH | Y | 공백 |
| EXCD | Y | 거래소코드 |
| SYMB | Y | 종목코드 |
| GUBN | Y | `0`:일, `1`:주, `2`:월 |
| BYMD | Y | 기준일자 (YYYYMMDD) |
| MODP | Y | 수정주가 `0`:미수정, `1`:수정 |
| KEYB | Y | 공백 |

### 응답 (output2 — 일봉 배열)

| Element | 설명 |
|---------|------|
| xymd | 일자 (YYYYMMDD) |
| open | 시가 |
| high | 고가 |
| low | 저가 |
| clos | 종가 |
| tvol | 거래량 |
| diff | 전일대비 |
| rate | 등락율 |
