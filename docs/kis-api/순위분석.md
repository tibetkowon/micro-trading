## 1. 거래량순위 (거래대금순 적용)

- **TR_ID**: `FHPST01710000`
- **Method/URL**: `GET /uapi/domestic-stock/v1/ranking/volume`
- **v2 변경사항**: `FID_BLNG_CLS_CODE=3` (거래대금순) 기본 적용으로 '진짜 대장주' 필터링

### 요청 Query

| Element | Required | 설명 |
|---------|----------|------|
| FID_COND_MRKT_DIV_CODE | Y | 시장분류코드 `J` |
| FID_COND_SCR_DIV_CODE | Y | 화면분류코드 `20171` |
| FID_INPUT_ISCD | Y | 종목코드 (전체: `0000`) |
| FID_DIV_CLS_CODE | Y | `0`:전체, `1`:보통주, `2`:우선주 |
| FID_BLNG_CLS_CODE | Y | `0`:평균이상, `1`:전체, **`3`:거래대금순** (v2 기본값), `4`:평균거래대금순 |
| FID_TRGT_CLS_CODE | Y | `111111111`:전체 |
| FID_TRGT_EXLS_CLS_CODE | Y | `000000`:제외없음 (투자위험/경고/주의/관리/정리/불성실/우선주/거래정지/ETF/ETN 각 1비트) |
| FID_INPUT_PRICE_1 | N | 최소가격 |
| FID_INPUT_PRICE_2 | N | 최대가격 |
| FID_VOL_CNT | N | 최소거래량 |
| FID_INPUT_DATE_1 | N | 공백 |

### 응답 (output) 주요 필드

| Element | 설명 |
|---------|------|
| data_rank | 순위 |
| mksc_shrn_iscd | 단축종목코드 |
| hts_kor_isnm | HTS한글종목명 |
| stck_prpr | 현재가 |
| prdy_vrss | 전일대비 |
| prdy_ctrt | 등락률 |
| acml_vol | 누적거래량 |
| acml_tr_pbmn | 누적거래대금 |

|---------|----------|------|

| fid_input_iscd | Y | 종목코드 `0000` |
| fid_rank_sort_cls_code | Y | 정렬 `0000` (등락률순) |

## 4. VI발동현황 (구현됨 — 순위형 아님)

- **TR_ID**: `FHPST01390000`
- **Method/URL**: `GET /uapi/domestic-stock/v1/quotations/inquire-vi-status`
- **용도**: 당일 VI(변동성완화장치) 발동 종목 조회. 순위 API가 아닌 **당일 전체 VI 이력 조회** 형태.
- **Source**: KIS GitHub `examples_llm/domestic_stock/inquire_vi_status/inquire_vi_status.py` 확인
- **활용 방식**: `FID_INPUT_DATE_1=오늘날짜`로 호출 → VI 발동 종목 리스트 추출 → ranking_type="vi_status"로 태깅

### 요청 Query

| Element | Required | 설명 |
|---------|----------|------|
| FID_DIV_CLS_CODE | Y | `0`:전체, `1`:상승VI, `2`:하락VI |
| FID_COND_SCR_DIV_CODE | Y | `20139` |
| FID_MRKT_CLS_CODE | Y | `0`:전체, `K`:KOSPI, `Q`:KOSDAQ |
| FID_INPUT_ISCD | Y | 종목코드 (`0000` = 전체) |
| FID_RANK_SORT_CLS_CODE | Y | `0`:전체, `1`:정적VI, `2`:동적VI, `3`:동시발동 |
| FID_INPUT_DATE_1 | Y | 조회일자 (`YYYYMMDD`) |
| FID_TRGT_CLS_CODE | N | 대상구분 |
| FID_TRGT_EXLS_CLS_CODE | N | 제외구분 |

### 응답 (output) 주요 필드

| Element | 설명 |
|---------|------|
| mksc_shrn_iscd | 단축종목코드 |
| hts_kor_isnm | 종목명 |
| vi_cls_code | VI발동상태 |
| bsop_date | 영업일자 |
| cntg_vi_hour | VI발동시간 |
| vi_cncl_hour | VI해제시간 |
| vi_kind_code | VI종류 (정적/동적) |
| vi_prc | VI발동가격 |
| vi_stnd_prc | 정적VI기준가격 |
| vi_dprt | 정적VI괴리율 |
| vi_dmc_stnd_prc | 동적VI기준가격 |
| vi_dmc_dprt | 동적VI괴리율 |
| vi_count | VI발동횟수 |

### 엔진 통합 방안
```
// 매 선정 사이클 시작 시 1회 호출
viStocks := GetVIStatus(today)
// vi_cncl_hour가 있는 종목 (해제된 종목) 만 후보로 활용
// → VI 해제 직후 급반등 노리는 전략
for _, v := range viStocks {
    if v.ViCnclHour != "" {
        candidate.RankingType = "vi_status"
    }
}
```
