## 1. 거래량순위

- **TR_ID**: `FHPST01710000`
- **Method/URL**: `GET /uapi/domestic-stock/v1/ranking/volume`

### 요청 Query

| Element | Required | 설명 |
|---------|----------|------|
| FID_COND_MRKT_DIV_CODE | Y | 시장분류코드 `J` |
| FID_COND_SCR_DIV_CODE | Y | 화면분류코드 `20171` |
| FID_INPUT_ISCD | Y | 종목코드 (전체: `0000`) |
| FID_DIV_CLS_CODE | Y | `0`:전체, `1`:보통주, `2`:우선주 |
| FID_BLNG_CLS_CODE | Y | `0`:평균이상, `1`:전체, `2`:증권포함 |
| FID_TRGT_CLS_CODE | Y | `111111111`:전체 |
| FID_TRGT_EXLS_CLS_CODE | Y | `000000`:제외없음 |
| FID_INPUT_PRICE_1 | N | 최소가격 |
| FID_INPUT_PRICE_2 | N | 최대가격 |
| FID_VOL_CNT | N | 최소거래량 |
| FID_INPUT_DATE_1 | N | 공백 |

### 응답 (output) 주요 필드

| Element | 설명 |
|---------|------|
| data_rank | 순위 |
| mksc_shrn_iscd | 단축종목코드 |
| hts_kor_isnm | HTS한글종목명 |
| stck_prpr | 현재가 |
| prdy_vrss | 전일대비 |
| prdy_ctrt | 등락률 |
| acml_vol | 누적거래량 |
| acml_tr_pbmn | 누적거래대금 |
