# [해외주식] 실시간 WebSocket API 명세

> **WebSocket URL**: `ws://ops.koreainvestment.com:21000` (실전) / `ws://ops.koreainvestment.com:31000` (모의)
> **Approval Key**: `POST /oauth2/Approval` — body: `grant_type`, `appkey`, `secretkey`

---

## API 목록

| API명 | TR_ID | 모의 |
|-------|-------|------|
| 실시간지연체결가 | `HDFSCNT0` | ❌ |
| 실시간호가 | `HDFSASP0` | ❌ |
| 실시간체결통보 | `H0GSCNI0` | `H0GSCNI9` |

---

## 1. 실시간체결가 (HDFSCNT0)

- **TR_ID**: `HDFSCNT0` (**모의 미지원**)
- **tr_key 형식**: `D` + 거래소3자리 + 종목코드
  - 예: `DNASAAPL` (NASDAQ AAPL), `DNYSAAPL` (NYSE AAPL), `DNYSTSLA` (NYSE TSLA), `DNFLNFLX` (NASDAQ NFLX)
- **시장구분**: `NYS`, `NAS`, `AMS`, `HKS`, `SHS`, `SZS`

### 응답 데이터 필드 (^ 구분)

| Field | 설명 |
|-------|------|
| RSYM | 실시간종목코드 (예: `DNASAAPL`) |
| ZDIV | 소수점자리수 |
| XYMD | 일자 (YYYYMMDD) |
| XHMS | 시간 (HHMMSS, 현지시각) |
| KHMS | 한국시간 (HHMMSS) |
| OPEN | 시가 |
| HIGH | 고가 |
| LOW | 저가 |
| LAST | **현재가** |
| SIGN | 전일대비부호 |
| DIFF | 전일대비 |
| RATE | 등락율 |
| PBID | 매수호가 |
| PASK | 매도호가 |
| VBID | 매수잔량 |
| VASK | 매도잔량 |
| EVOL | 체결량 |
| TVOL | 누적거래량 |
| TAMT | 누적거래대금 |
| MTYP | 시장구분 (`1`:장중, `2`:장전, `3`:장후) |
| STRN | 체결강도 |

---

## 2. 실시간호가 (HDFSASP0)

- **TR_ID**: `HDFSASP0` (**모의 미지원**)
- **tr_key**: `D` + 거래소3자리 + 종목코드 (체결가와 동일 형식)

### 응답 데이터 필드 (주요)

| Field | 설명 |
|-------|------|
| RSYM | 실시간종목코드 |
| KHMS | 한국시간 |
| PASK1~5 | 매도호가 1~5단계 |
| PBID1~5 | 매수호가 1~5단계 |
| VASK1~5 | 매도잔량 1~5단계 |
| VBID1~5 | 매수잔량 1~5단계 |

---

## 3. 실시간체결통보 (H0GSCNI0)

- **TR_ID**: `H0GSCNI0` (실전) / `H0GSCNI9` (모의)
- **tr_key**: **HTS ID** (`KIS_HTS_ID` 환경변수) — 국내 체결통보와 동일

> **암호화**: 국내 체결통보(`H0STCNI0`)와 동일하게 AES-256-CBC + PKCS7 암호화.
> 구독 성공 JSON의 `body.output.key` / `.iv` 를 사용하여 복호화.

### 응답 데이터 필드 (^ 구분, 복호화 후)

| Field | 설명 |
|-------|------|
| ODER_NO | 주문번호 |
| SELN_BYOV_CLS | 매도매수구분 (`01`:매도, `02`:매수) |
| STCK_SHRN_ISCD | 단축종목코드 |
| CNTG_QTY | **체결수량** |
| CNTG_UNPR | **체결단가** |
| CNTG_YN | **체결여부 (`2`=체결)** — 국내와 동일 |
| RFUS_YN | 거부여부 (`0`:정상, `1`:거부) |
| ORDEN_COND | 거래소구분 (`6`:NASDAQ, `7`:NYSE, `8`:AMEX) |

---

## 구현 주의사항

- **국내 H0STCNI0 기존 구독 재사용**: `H0GSCNI0`도 tr_key=HTS ID로 동일하게 구독.
  `ORDEN_COND` 필드로 국내(빈값)/해외(6/7/8) 판별.
- **tr_key 대소문자**: `DNASAAPL` — 거래소 대문자 + 종목코드 대문자
- **MTYP 필드**: 장전/장중/장후 구분 → 장중(`1`)에만 매매 신호 처리 권장
- **지연 시세**: WebSocket 체결가도 15분 지연될 수 있음 (실전 계좌 전용 플랜에서 실시간 제공)
