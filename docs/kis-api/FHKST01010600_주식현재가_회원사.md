# 주식현재가 회원사

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `주식현재가 회원사` |
| API ID | `v1_국내주식-013` |
| 실전 TR_ID | `FHKST01010600` |
| 모의 TR_ID | `FHKST01010600` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/quotations/inquire-member` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `https://openapivts.koreainvestment.com:29443`

> 주식 현재가 회원사 API입니다. 회원사의 투자 정보를 확인할 수 있습니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `FID_COND_MRKT_DIV_CODE` | FID 조건 시장 분류 코드 | string | Y | J:KRX, NX:NXT, UN:통합 |
| `FID_INPUT_ISCD` | FID 입력 종목코드 | string | Y | 종목번호 (6자리); ETN의 경우, Q로 시작 (EX. Q500001) |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | Y | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | Y | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |
