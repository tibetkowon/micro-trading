# 국내주식 증권사별 투자의견

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `국내주식 증권사별 투자의견` |
| API ID | `국내주식-189` |
| 실전 TR_ID | `FHKST663400C0` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/quotations/invest-opbysec` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `미지원`

> 국내주식 증권사별 투자의견 API입니다.
한국투자 HTS(eFriend Plus) &gt; [0608] 증권사별 투자의견 화면 의 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.

한 번의 호출에 20건까지 조회가 가능하기에, 일자 파라미터(FID_INPUT_DATE_1, FID_INPUT_DATE_2)를 조절하여 다음 데이터 조회하시기 바랍니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `FID_COND_MRKT_DIV_CODE` | 조건시장분류코드 | string | Y | J(시장 구분 코드) |
| `FID_COND_SCR_DIV_CODE` | 조건화면분류코드 | string | Y | 16634(Primary key) |
| `FID_INPUT_ISCD` | 입력종목코드 | string | Y | 회원사코드 (kis developers 포탈 사이트 포럼-> FAQ -> 종목정보 다운로드(국내) 참조) |
| `FID_DIV_CLS_CODE` | 분류구분코드 | string | Y | 전체(0) 매수(1) 중립(2) 매도(3) |
| `FID_INPUT_DATE_1` | 입력날짜1 | string | Y | 이후 ~ |
| `FID_INPUT_DATE_2` | 입력날짜2 | string | Y | ~ 이전 |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |

## Response Body

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `rt_cd` | 성공 실패 여부 | string | Y |  |
| `msg_cd` | 응답코드 | string | Y |  |
| `msg1` | 응답메세지 | string | Y |  |
| `output` | 응답상세 | object array | Y | array |
| `stck_bsop_date` | 주식영업일자 | string | Y |  |
| `stck_shrn_iscd` | 주식단축종목코드 | string | Y |  |
| `hts_kor_isnm` | HTS한글종목명 | string | Y |  |
| `invt_opnn` | 투자의견 | string | Y |  |
| `invt_opnn_cls_code` | 투자의견구분코드 | string | Y |  |
| `rgbf_invt_opnn` | 직전투자의견 | string | Y |  |
| `rgbf_invt_opnn_cls_code` | 직전투자의견구분코드 | string | Y |  |
| `mbcr_name` | 회원사명 | string | Y |  |
| `stck_prpr` | 주식현재가 | string | Y |  |
| `prdy_vrss` | 전일대비 | string | Y |  |
| `prdy_vrss_sign` | 전일대비부호 | string | Y |  |
| `prdy_ctrt` | 전일대비율 | string | Y |  |
| `hts_goal_prc` | HTS목표가격 | string | Y |  |
| `stck_prdy_clpr` | 주식전일종가 | string | Y |  |
| `stft_esdg` | 주식선물괴리도 | string | Y |  |
| `dprt` | 괴리율 | string | Y |  |
