# 국내기관_외국인 매매종목가집계

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `국내기관_외국인 매매종목가집계` |
| API ID | `국내주식-037` |
| 실전 TR_ID | `FHPTJ04400000` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/quotations/foreign-institution-total` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `모의투자 미지원`

> 국내기관_외국인 매매종목가집계 API입니다.

HTS(efriend Plus) [0440] 외국인/기관 매매종목 가집계 화면을 API로 구현한 사항으로 화면을 함께 보시면 기능 이해가 쉽습니다.

증권사 직원이 장중에 집계/입력한 자료를 단순 누계한 수치로서, 
입력시간은 외국인 09:30, 11:20, 13:20, 14:30 / 기관종합 10:00, 11:20, 13:20, 14:30 이며, 
입력한 시간은 ±10분정도 차이가 발생할 수 있으며, 장운영 사정에 다라 변동될 수 있습니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `FID_COND_MRKT_DIV_CODE` | 시장 분류 코드 | string | Y | V(Default) |
| `FID_COND_SCR_DIV_CODE` | 조건 화면 분류 코드 | string | Y | 16449(Default) |
| `FID_INPUT_ISCD` | 입력 종목코드 | string | Y | 0000:전체, 0001:코스피, 1001:코스닥; ...; 포탈 (FAQ : 종목정보 다운로드(국내) - 업종코드 참조) |
| `FID_DIV_CLS_CODE` | 분류 구분 코드 | string | Y | 0: 수량정열, 1: 금액정열 |
| `FID_RANK_SORT_CLS_CODE` | 순위 정렬 구분 코드 | string | Y | 0: 순매수상위, 1: 순매도상위 |
| `FID_ETC_CLS_CODE` | 기타 구분  정렬 | string | Y | 0:전체 1:외국인 2:기관계 3:기타 |

| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
