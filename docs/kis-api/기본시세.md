# [국내주식] 기본시세 API 명세 (현재 사용 중인 TR_ID 중심)

> **Domain**: 실전/모의 공통 `https://openapi.koreainvestment.com:9443`
> **공통 헤더**: `content-type: application/json; charset=utf-8`, `authorization: Bearer {token}`, `appkey`, `appsecret`, `tr_id`

---

## 1. 주식현재가 시세

- **Method/URL**: `GET /uapi/domestic-stock/v1/quotations/inquire-price`
- **TR_ID**: `FHKST01010100` (실전/모의 공통)

> 실시간 시세가 필요하면 WebSocket `H0STCNT0` 사용

### 요청 Query

| Element | Required | 설명 |
|---------|----------|------|
| FID_COND_MRKT_DIV_CODE | Y | 시장분류코드 `J` |
| FID_INPUT_ISCD | Y | 종목코드 (6자리) |

### 응답 (output) 주요 필드

| Element | 설명 |
|---------|------|
| stck_prpr | 주식현재가 |
| prdy_vrss | 전일대비 |
| prdy_ctrt | 전일대비율 |
| acml_vol | 누적거래량 |
| hts_avls | HTS 시가총액 |
| stck_hgpr | 주식최고가 (52주) |
| stck_lwpr | 주식최저가 (52주) |
| per | PER |
| pbr | PBR |

---

## 2. 국내주식 기간별 시세 (일봉)

- **Method/URL**: `GET /uapi/domestic-stock/v1/quotations/inquire-daily-itemchartprice`
- **TR_ID**: `FHKST03010100` (실전/모의 공통)

### 요청 Query

| Element | Required | 설명 |
|---------|----------|------|
| FID_COND_MRKT_DIV_CODE | Y | `J` |
| FID_INPUT_ISCD | Y | 종목코드 |
| FID_INPUT_DATE_1 | Y | 시작일자 (YYYYMMDD) |
| FID_INPUT_DATE_2 | Y | 종료일자 |
| FID_PERIOD_DIV_CODE | Y | `D`:일, `W`:주, `M`:월 |
| FID_ORG_ADJ_PRC | Y | `0`:수정주가, `1`:원주가 |

### 응답 (output2 — 일봉 배열)

| Element | 설명 |
|---------|------|
| stck_bsop_date | 영업일자 |
| stck_oprc | 시가 |
| stck_hgpr | 고가 |
| stck_lwpr | 저가 |
| stck_clpr | 종가 |
| acml_vol | 누적거래량 |

---

## 3. 주식당일분봉조회

- **Method/URL**: `GET /uapi/domestic-stock/v1/quotations/inquire-time-itemchartprice`
- **TR_ID**: `FHKST03010200` (실전/모의 공통)

### 요청 Query

| Element | Required | 설명 |
|---------|----------|------|
| FID_ETC_CLS_CODE | Y | 공백 |
| FID_COND_MRKT_DIV_CODE | Y | `J` |
| FID_INPUT_ISCD | Y | 종목코드 |
| FID_INPUT_HOUR_1 | Y | 조회 기준 시각 (HHMMSS) |
| FID_PW_DATA_INCU_YN | Y | `Y`:과거포함, `N`:미포함 |

### 응답 (output2 — 분봉 배열)

| Element | 설명 |
|---------|------|
| stck_bsop_date | 영업일자 |
| stck_cntg_hour | 체결시간 |
| stck_prpr | 현재가 |
| stck_oprc | 시가 |
| stck_hgpr | 고가 |
| stck_lwpr | 저가 |
| cntg_vol | 체결거래량 |
