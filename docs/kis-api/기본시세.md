# [국내주식] 기본시세 API 명세 (현재 사용 중인 TR_ID 중심)

> **Domain**: 실전/모의 공통 `https://openapi.koreainvestment.com:9443`
> **공통 헤더**: `content-type: application/json; charset=utf-8`, `authorization: Bearer {token}`, `appkey`, `appsecret`, `tr_id`

---

## 1. 주식현재가 시세

- **Method/URL**: `GET /uapi/domestic-stock/v1/quotations/inquire-price`
- **TR_ID**: `FHKST01010100` (실전/모의 공통)

> 실시간 시세가 필요하면 WebSocket `H0STCNT0` 사용

### 요청 Query

| Element | Required | 설명 |
|---------|----------|------|
| FID_COND_MRKT_DIV_CODE | Y | 시장분류코드 `J` |
| FID_INPUT_ISCD | Y | 종목코드 (6자리) |

### 응답 (output) 주요 필드

| Element | 설명 |
|---------|------|
| stck_prpr | 주식현재가 |
| prdy_vrss | 전일대비 |
| prdy_ctrt | 전일대비율 |
| acml_vol | 누적거래량 |
| hts_avls | HTS 시가총액 |
| stck_hgpr | 주식최고가 (52주) |
| stck_lwpr | 주식최저가 (52주) |
| per | PER |
| pbr | PBR |

## 3. 주식당일분봉조회 (전체 — 단일 호출)

- **Method/URL**: `GET /uapi/domestic-stock/v1/quotations/inquire-time-dailychartprice`
- **TR_ID**: `FHKST03010230` (실전/모의 공통 — KIS 개발자 포털에서 검증 필요)
- **특징**: 당일 분봉 최대 **120건**을 **1회 호출**로 반환. `inquire-time-itemchartprice` 페이지네이션 대비 API 호출 수 1/4~1/6로 절감. 지표 계산(RSI, MACD, VWAP) 전용.

### 요청 Query

| Element | Required | 설명 |
|---------|----------|------|
| FID_COND_MRKT_DIV_CODE | Y | `J` |
| FID_INPUT_ISCD | Y | 종목코드 (6자리) |
| FID_INPUT_DATE_1 | Y | 조회 일자 (YYYYMMDD) — 당일: `time.Now().Format("20060102")` |
| FID_INPUT_HOUR_1 | Y | 조회 기준 시각 (HHMMSS) — 보통 현재시각 |
| FID_PW_DATA_INCU_YN | Y | `N` (과거 포함 불필요) |

### 응답 (output2 — 분봉 배열, 최대 120건)

`inquire-time-itemchartprice`의 output2와 동일한 필드 구조.

| Element | 설명 |
|---------|------|
| stck_bsop_date | 영업일자 |
| stck_cntg_hour | 체결시간 |
| stck_prpr | 현재가 |
| stck_oprc | 시가 |
| stck_hgpr | 고가 |
| stck_lwpr | 저가 |
| cntg_vol | 체결거래량 |

> **당일 데이터 조회 여부**: 장 중 현재 날짜를 `FID_INPUT_DATE_1`에 전달하면 09:00~현재까지 누적된 분봉을 반환. 장 시작 직후(봉 수 부족)에는 가용 봉만 반환됨.

## 4. 주식당일분봉조회 (시간별 페이지네이션, 레거시)

> ⚠️ 한 번에 최대 ~30봉 반환 → 120봉 필요 시 4~6회 호출 필요. TPS 초과(`EGW00201`) 유발 가능. 지표 계산에는 섹션 3의 `inquire-time-dailychartprice` 사용 권장.

- **Method/URL**: `GET /uapi/domestic-stock/v1/quotations/inquire-time-itemchartprice`

| FID_INPUT_HOUR_1 | Y | 조회 기준 시각 (HHMMSS) |
| FID_PW_DATA_INCU_YN | Y | `Y`:과거포함, `N`:미포함 |

### 응답 (output2 — 분봉 배열)
