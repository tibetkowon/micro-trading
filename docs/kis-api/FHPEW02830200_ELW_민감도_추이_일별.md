# ELW 민감도 추이(일별)

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `ELW 민감도 추이(일별)` |
| API ID | `국내주식-176` |
| 실전 TR_ID | `FHPEW02830200` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/elw/v1/quotations/sensitivity-trend-daily` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `미지원`

> ELW 민감도 추이(일별) API입니다.
한국투자 HTS(eFriend Plus) &gt; [0283] ELW 민감도 추이 화면의 "일자별" 민감도추이 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `FID_COND_MRKT_DIV_CODE` | 조건시장분류코드 | string | Y | 시장구분코드 (W) |
| `FID_INPUT_ISCD` | 입력종목코드 | string | Y | ex)(58J438(KBJ438삼성전자풋) |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |

## Response Body

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `rt_cd` | 성공 실패 여부 | string | Y |  |
| `msg_cd` | 응답코드 | string | Y |  |
| `msg1` | 응답메세지 | string | Y |  |
| `output` | 응답상세 | object array | Y | array |
| `stck_bsop_date` | 주식영업일자 | string | Y |  |
| `elw_prpr` | ELW현재가 | string | Y |  |
| `prdy_vrss` | 전일대비 | string | Y |  |
| `prdy_vrss_sign` | 전일대비부호 | string | Y |  |
| `prdy_ctrt` | 전일대비율 | string | Y |  |
| `hts_thpr` | HTS이론가 | string | Y |  |
| `delta_val` | 델타값 | string | Y |  |
| `gama` | 감마 | string | Y |  |
| `theta` | 세타 | string | Y |  |
| `vega` | 베가 | string | Y |  |
| `rho` | 로우 | string | Y |  |
