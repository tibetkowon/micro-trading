# 국내주식 예상체결지수 추이

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `국내주식 예상체결지수 추이` |
| API ID | `국내주식-121` |
| 실전 TR_ID | `FHPST01840000` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/quotations/exp-index-trend` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `미지원`

> 국내주식 예상체결지수 추이 API입니다. 
한국투자 HTS(eFriend Plus) &gt; [0184] 예상체결지수 추이 화면의 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `FID_MKOP_CLS_CODE` | 장운영 구분 코드 | string | Y | 1: 장시작전, 2: 장마감 |
| `FID_INPUT_HOUR_1` | 입력 시간1 | string | Y | 10(10초), 30(30초), 60(1분), 600(10분) |
| `FID_INPUT_ISCD` | 입력 종목코드 | string | Y | 0000:전체, 0001:코스피, 1001:코스닥, 2001:코스피200, 4001: KRX100 |
| `FID_COND_MRKT_DIV_CODE` | 조건 시장 분류 코드 | string | Y | 시장구분코드 (주식 U) |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |

## Response Body

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `rt_cd` | 성공 실패 여부 | string | Y |  |
| `msg_cd` | 응답코드 | string | Y |  |
| `msg1` | 응답메세지 | string | Y |  |
| `output` | 응답상세 | object array | Y | array |
| `stck_cntg_hour` | 주식 단축 종목코드 | string | Y |  |
| `bstp_nmix_prpr` | HTS 한글 종목명 | string | Y |  |
| `prdy_vrss_sign` | 주식 현재가 | string | Y |  |
| `bstp_nmix_prdy_vrss` | 전일 대비 | string | Y |  |
| `prdy_ctrt` | 전일 대비 부호 | string | Y |  |
| `acml_vol` | 전일 대비율 | string | Y |  |
| `acml_tr_pbmn` | 기준가 대비 현재가 | string | Y |  |
