# [국내주식] 주문·계좌 API 명세 (현재 사용 중인 TR_ID 중심)

> **Domain**: 실전 `https://openapi.koreainvestment.com:9443` / 모의 `:29443`
> **공통 헤더**: `content-type: application/json; charset=utf-8`, `authorization: Bearer {token}`, `appkey`, `appsecret`, `tr_id`

---

## 1. 주식주문 (현금 매수/매도)

- **Method/URL**: `POST /uapi/domestic-stock/v1/trading/order-cash`
- **TR_ID**: 매수 `TTTC0012U` / 매도 `TTTC0011U` (모의: `VTTC0012U` / `VTTC0011U`)

### 요청 Body

| Element | Required | Type | 설명 |
|---------|----------|------|------|
| CANO | Y | string(8) | 종합계좌번호 앞 8자리 |
| ACNT_PRDT_CD | Y | string(2) | 계좌상품코드 뒤 2자리 |
| PDNO | Y | string(12) | 종목코드 (6자리) |
| ORD_DVSN | Y | string(2) | 주문구분 — `00`:지정가, `01`:시장가 |
| ORD_QTY | Y | string(10) | 주문수량 |
| ORD_UNPR | Y | string(19) | 주문단가 (시장가 시 `"0"`) |

### 응답 Body (output)

| Element | 설명 |
|---------|------|
| KRX_FWDG_ORD_ORGNO | 한국거래소전송주문조직번호 (취소 시 사용) |
| ORNO | 주문번호 (취소 시 사용) |
| ORD_TMD | 주문시각 (HHMMSS) |

---

## 2. 주식주문 (정정·취소)

- **Method/URL**: `POST /uapi/domestic-stock/v1/trading/order-rvsecncl`
- **TR_ID**: `TTTC0013U` (모의: `VTTC0013U`)

### 요청 Body

| Element | Required | Type | 설명 |
|---------|----------|------|------|
| CANO | Y | string(8) | 종합계좌번호 |
| ACNT_PRDT_CD | Y | string(2) | 계좌상품코드 |
| KRX_FWDG_ORD_ORGNO | Y | string(3) | 주문 시 반환된 조직번호 |
| ORGN_ODNO | Y | string(10) | 원주문번호 |
| ORD_DVSN | Y | string(2) | `00`:지정가 |
| RVSE_CNCL_DVSN_CD | Y | string(2) | `01`:정정, `02`:취소 |
| ORD_QTY | Y | string(10) | 주문수량 (`0` = 전량) |
| ORD_UNPR | Y | string(19) | 주문단가 (취소 시 `"0"`) |
| QTY_ALL_ORD_YN | Y | string(1) | 잔량전부주문여부 `Y`/`N` |

## 3. 주식정정취소가능주문조회

- **Method/URL**: `GET /uapi/domestic-stock/v1/trading/inquire-psbl-rvsecncl`
- **TR_ID**: `TTTC0084R` (**모의 미지원**)

### 요청 Query

| Element | Required | 설명 |
|---------|----------|------|
| CANO | Y | 종합계좌번호 |
| ACNT_PRDT_CD | Y | 계좌상품코드 |
| CTX_AREA_FK100 | N | 연속조회검색조건100 (페이지네이션) |
| CTX_AREA_NK100 | N | 연속조회키100 |
| INQR_DVSN_1 | Y | `0`:조회전체, `1`:매도, `2`:매수 |
| INQR_DVSN_2 | Y | `0`:전체, `1`:지정가, `2`:시장가 |

### 응답 (output)

| Element | 설명 |
|---------|------|
| ord_dt | 주문일자 |
| orno | 주문번호 |
| pdno | 종목코드 |
| ord_qty | 주문수량 |
| ord_unpr | 주문단가 |
| psbl_qty | 정정취소가능수량 |
| sll_buy_dvsn_cd | 매도매수구분 (`01`:매도, `02`:매수) |

> **페이지네이션**: `ctx_area_fk100` / `ctx_area_nk100` → `strings.TrimSpace()` 후 둘 다 빈 문자열이면 마지막 페이지.

## 4. 주식일별주문체결조회

- **Method/URL**: `GET /uapi/domestic-stock/v1/trading/inquire-daily-ccld`
- **TR_ID**: `TTTC0081R` (3개월 이내) / 모의: `VTTC0081R`

> **⚠️ `TTTC8001R`은 구버전 — 사용 금지**

### 요청 Query

| Element | Required | 설명 |
|---------|----------|------|
| CANO | Y | 종합계좌번호 |
| ACNT_PRDT_CD | Y | 계좌상품코드 |
| INQR_STRT_DT | Y | 조회시작일자 (YYYYMMDD) |
| INQR_END_DT | Y | 조회종료일자 |
| SLL_BUY_DVSN_CD | Y | `00`:전체, `01`:매도, `02`:매수 |
| INQR_DVSN | Y | `00`:역순, `01`:정순 |
| PDNO | N | 종목코드 (전체조회 시 공백) |
| CCLD_DVSN | Y | `00`:전체, `01`:체결, `02`:미체결 |
| CTX_AREA_FK100 | N | 연속조회검색조건 |
| CTX_AREA_NK100 | N | 연속조회키 |

### 응답 (output1 — 건별)

| Element | 설명 |
|---------|------|
| ord_dt | 주문일자 |
| orno | 주문번호 |
| pdno | 종목코드 |
| prdt_name | 종목명 |
| sll_buy_dvsn_cd | 매도매수구분 (`01`:매도, `02`:매수) |
| ord_qty | 주문수량 |
| ord_unpr | 주문단가 |
| cncl_yn | 취소여부 (`Y`/`N`) — **앱 레벨에서 `cncl_yn == "Y"` 필터링 필수** (CANC_YN 파라미터는 실질 필터링 안 됨) |
| tot_ccld_qty | 총체결수량 |
| avg_prvs | 평균단가 |
| pchs_avg_pric | 매입평균가격 |
| ord_tmd | 주문시각 |

> **⚠️ `rt_cd` 체크**: HTTP 200이어도 `rt_cd == "1"` 이면 API 오류. 반드시 파싱 필요.
