# 종목별 프로그램매매추이(일별)

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `종목별 프로그램매매추이(일별)` |
| API ID | `국내주식-113` |
| 실전 TR_ID | `FHPPG04650201` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/quotations/program-trade-by-stock-daily` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `미지원`

> 국내주식 종목별 프로그램매매추이(일별) API입니다.
한국투자 HTS(eFriend Plus) &gt; [0465] 종목별 프로그램 매매추이 화면(혹은 한국투자 MTS &gt; 국내 현재가 &gt; 기타수급 &gt; 프로그램) 의 "일자별" 클릭 시 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `FID_COND_MRKT_DIV_CODE` | 조건 시장 분류 코드 | string | Y | KRX : J , NXT : NX, 통합 : UN |
| `FID_INPUT_ISCD` | 입력 종목코드 | string | Y | 종목코드 |
| `FID_INPUT_DATE_1` | 입력 날짜1 | string | Y | 기준일 (ex 0020240308), 미입력시 당일부터 조회 |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |

## Response Body

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `rt_cd` | 성공 실패 여부 | string | Y |  |
| `msg_cd` | 응답코드 | string | Y |  |
| `msg1` | 응답메세지 | string | Y |  |
| `output` | 응답상세 | object array | Y | array |
| `stck_bsop_date` | 주식 영업 일자 | string | Y |  |
| `stck_clpr` | 주식 종가 | string | Y |  |
| `prdy_vrss` | 전일 대비 | string | Y |  |
| `prdy_vrss_sign` | 전일 대비 부호 | string | Y |  |
| `prdy_ctrt` | 전일 대비율 | string | Y |  |
| `acml_vol` | 누적 거래량 | string | Y |  |
| `acml_tr_pbmn` | 누적 거래 대금 | string | Y |  |
| `whol_smtn_seln_vol` | 전체 합계 매도 거래량 | string | Y |  |
| `whol_smtn_shnu_vol` | 전체 합계 매수2 거래량 | string | Y |  |
| `whol_smtn_ntby_qty` | 전체 합계 순매수 수량 | string | Y |  |
| `whol_smtn_seln_tr_pbmn` | 전체 합계 매도 거래 대금 | string | Y |  |
| `whol_smtn_shnu_tr_pbmn` | 전체 합계 매수2 거래 대금 | string | Y |  |
| `whol_smtn_ntby_tr_pbmn` | 전체 합계 순매수 거래 대금 | string | Y |  |
| `whol_ntby_vol_icdc` | 전체 순매수 거래량 증감 | string | Y |  |
| `whol_ntby_tr_pbmn_icdc2` | 전체 순매수 거래 대금 증감2 | string | Y |  |
