# 종목별 외인기관 추정가집계

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `종목별 외인기관 추정가집계` |
| API ID | `v1_국내주식-046` |
| 실전 TR_ID | `HHPTJ04160200` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/quotations/investor-trend-estimate` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `모의투자 미지원`

> 국내주식 종목별 외국인, 기관 추정가집계 API입니다.

한국투자 MTS &gt; 국내 현재가 &gt; 투자자 &gt; 투자자동향 탭 &gt; 왼쪽구분을 '추정(주)'로 선택 시 확인 가능한 데이터를 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.

증권사 직원이 장중에 집계/입력한 자료를 단순 누계한 수치로서,
입력시간은 외국인 09:30, 11:20, 13:20, 14:30 / 기관종합 10:00, 11:20, 13:20, 14:30 이며, 사정에 따라 변동될 수 있습니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `MKSC_SHRN_ISCD` | 종목코드 | string | Y | 종목코드 |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |

## Response Body

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `rt_cd` | 성공 실패 여부 | string | Y |  |
| `msg_cd` | 응답코드 | string | Y |  |
| `msg1` | 응답메세지 | string | Y |  |
| `output2` | 응답상세 | object array | Y | Array |
| `bsop_hour_gb` | 입력구분 | string | Y | 1: 09시 30분 입력; 2: 10시 00분 입력 ; 3: 11시 20분 입력 ; 4: 13시 20분 입력 ; 5: 14시 30분 입력 |
| `frgn_fake_ntby_qty` | 외국인수량(가집계) | string | Y |  |
| `orgn_fake_ntby_qty` | 기관수량(가집계) | string | Y |  |
| `sum_fake_ntby_qty` | 합산수량(가집계) | string | Y |  |
