# 종목별일별매수매도체결량

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `종목별일별매수매도체결량` |
| API ID | `v1_국내주식-056` |
| 실전 TR_ID | `FHKST03010800` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/quotations/inquire-daily-trade-volume` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `모의투자 미지원`

> 종목별일별매수매도체결량 API입니다. 실전계좌의 경우, 한 번의 호출에 최대 100건까지 확인 가능합니다.
국내주식 종목의 일별 매수체결량, 매도체결량 데이터를 확인할 수 있습니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `FID_COND_MRKT_DIV_CODE` | FID 조건 시장 분류 코드 | string | Y | J: KRX, NX: NXT, UN: 통합 |
| `FID_INPUT_ISCD` | FID 입력 종목코드 | string | Y | 005930 |
| `FID_INPUT_DATE_1` | FID 입력 날짜1 | string | Y | from |
| `FID_INPUT_DATE_2` | FID 입력 날짜2 | string | Y | to |
| `FID_PERIOD_DIV_CODE` | FID 기간 분류 코드 | string | Y | D |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |

## Response Body

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `rt_cd` | 성공 실패 여부 | string | Y |  |
| `msg_cd` | 응답코드 | string | Y |  |
| `msg1` | 응답메세지 | string | Y |  |
| `output1` | 응답상세 | object | Y |  |
| `shnu_cnqn_smtn` | 매수 체결량 합계 | string | Y |  |
| `seln_cnqn_smtn` | 매도 체결량 합계 | string | Y |  |
| `output2` | 응답상세2 | object array | Y | array |
| `stck_bsop_date` | 거래상태정보 | string | Y |  |
| `total_seln_qty` | 총 매도 수량 | string | Y |  |
| `total_shnu_qty` | 총 매수 수량 | string | Y |  |
