# 주식일별분봉조회

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `주식일별분봉조회` |
| API ID | `국내주식-213` |
| 실전 TR_ID | `FHKST03010230` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/quotations/inquire-time-dailychartprice` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `모의투자 미지원`

> 주식일별분봉조회 API입니다. 

실전계좌의 경우, 한 번의 호출에 최대 120건까지 확인 가능하며, 
FID_INPUT_DATE_1, FID_INPUT_HOUR_1 이용하여 과거일자 분봉조회 가능합니다.

※ 과거 분봉 조회 시, 당사 서버에서 보관하고 있는 만큼의 데이터만 확인이 가능합니다. (최대 1년 분봉 보관)

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `FID_COND_MRKT_DIV_CODE` | 조건 시장 분류 코드 | string | Y | J:KRX, NX:NXT, UN:통합 |
| `FID_INPUT_ISCD` | 입력 종목코드 | string | Y | 종목코드 (ex 005930 삼성전자) |
| `FID_INPUT_HOUR_1` | 입력 시간1 | string | Y | 입력 시간(ex 13시 130000) |
| `FID_INPUT_DATE_1` | 입력 날짜1 | string | Y | 입력 날짜(20241023) |
| `FID_PW_DATA_INCU_YN` | 과거 데이터 포함 여부 | string | Y |  |
| `FID_FAKE_TICK_INCU_YN` | 허봉 포함 여부 | string | N | 공백 필수 입력 |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | 공백 : 초기 조회 ; N : 다음 데이터 조회 (output header의 tr_cont가 M일 경우) |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `rt_cd` | 성공 실패 여부 | string | Y |  |
| `msg_cd` | 응답코드 | string | Y |  |

| `stck_prdy_clpr` | 주식 전일 종가 | string | Y |  |

| `acml_tr_pbmn` | 누적 거래 대금 | string | Y |  |
| `hts_kor_isnm` | HTS 한글 종목명 | string | Y |  |
| `stck_prpr` | 주식 현재가 | string | Y |  |
| `output2` | 응답상세 | object array | Y | array |
| `stck_bsop_date` | 주식 영업 일자 | string | Y |  |
