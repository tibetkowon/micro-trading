# [해외주식] 주문·계좌 API 명세

> **Domain**: 실전 `https://openapi.koreainvestment.com:9443` / 모의 `:29443`
> **공통 헤더**: `content-type: application/json; charset=utf-8`, `authorization: Bearer {token}`, `appkey`, `appsecret`, `tr_id`

**미국 운영시간(KST)**: 서머타임 `22:30~05:00` / 비서머타임 `23:30~06:00`

---

## 1. 해외주식 주문 (매수/매도)

- **Method/URL**: `POST /uapi/overseas-stock/v1/trading/order`
- **TR_ID**: 미국 매수 `TTTT1002U` / 미국 매도 `TTTT1006U` (모의: `VTTT1002U` / `VTTT1001U`)

### 요청 Body

| Element | Required | Type | 설명 |
|---------|----------|------|------|
| CANO | Y | string(8) | 종합계좌번호 앞 8자리 |
| ACNT_PRDT_CD | Y | string(2) | 계좌상품코드 뒤 2자리 |
| OVRS_EXCG_CD | Y | string(4) | 거래소코드 — `NASD`/`NYSE`/`AMEX`/`SEHK`/`SHAA`/`SZAA`/`TKSE` |
| PDNO | Y | string(12) | 종목코드 (예: `AAPL`, `TSLA`) |
| ORD_QTY | Y | string(10) | 주문수량 |
| OVRS_ORD_UNPR | Y | string(19) | 1주당 가격 (시장가: `"0"`) |
| ORD_DVSN | Y | string(2) | `00`:지정가, `32`:LOO, `34`:LOC, `35`:MOO, `36`:MOC |
| ORD_SVR_DVSN_CD | Y | string(1) | `"0"` |

### 응답 Body (output)

| Element | 설명 |
|---------|------|
| KRX_FWDG_ORD_ORGNO | 주문조직번호 (취소 시 사용) |
| ORNO | 주문번호 |
| ORD_TMD | 주문시각 (HHMMSS) |

| Element | Required | Type | 설명 |

| CANO | Y | string(8) | 종합계좌번호 |
| ACNT_PRDT_CD | Y | string(2) | 계좌상품코드 |
| OVRS_EXCG_CD | Y | string(4) | 거래소코드 |
| PDNO | Y | string(12) | 종목코드 |
| ORGN_ODNO | Y | string(10) | 원주문번호 |

| ORD_QTY | Y | string(10) | 주문수량 |

| ORD_SVR_DVSN_CD | Y | string(1) | `"0"` |

## 3. 매수가능금액조회

- **Method/URL**: `GET /uapi/overseas-stock/v1/trading/inquire-psamount`
- **TR_ID**: `TTTS3007R` (모의: `VTTS3007R`)

### 요청 Query

| Element | Required | 설명 |
|---------|----------|------|
| CANO | Y | 종합계좌번호 |
| ACNT_PRDT_CD | Y | 계좌상품코드 |
| OVRS_EXCG_CD | Y | 거래소코드 |
| OVRS_ORD_UNPR | Y | 주문단가 (USD) |
| ITEM_CD | Y | 종목코드 |

### 응답 (output)

| Element | 설명 |
|---------|------|
| ovrs_max_ord_psbl_amt | 해외최대주문가능금액 |
| ord_psbl_frcr_amt | 주문가능외화금액 |
| max_ord_psbl_qty | 최대주문가능수량 |

## 4. 미체결내역 조회

- **Method/URL**: `GET /uapi/overseas-stock/v1/trading/inquire-nccs`
- **TR_ID**: `TTTS3018R` (**모의 미지원**)

### 요청 Query

| Element | Required | 설명 |
|---------|----------|------|
| CANO | Y | 종합계좌번호 |
| ACNT_PRDT_CD | Y | 계좌상품코드 |
| OVRS_EXCG_CD | Y | 거래소코드 (`NASD` 등) |
| SORT_SQN | Y | 정렬순서 `DS`:역순, `AS`:정순 |
| CTX_AREA_FK200 | N | 연속조회검색조건 |
| CTX_AREA_NK200 | N | 연속조회키 |

### 응답 (output) 주요 필드

| Element | 설명 |
|---------|------|
| ord_dt | 주문일자 |
| odno | 주문번호 |
| pdno | 종목코드 |
| ovrs_item_name | 종목명 |
| sll_buy_dvsn_cd | 매도매수구분 |
| ft_ord_qty | 주문수량 |
| ft_ord_unpr3 | 주문단가 |
| ft_ccld_qty | 체결수량 |
| nccs_qty | 미체결수량 |
