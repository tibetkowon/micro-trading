# 국내주식업종기간별시세(일_주_월_년)

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `국내주식업종기간별시세(일_주_월_년)` |
| API ID | `v1_국내주식-021` |
| 실전 TR_ID | `FHKUP03500100` |
| 모의 TR_ID | `FHKUP03500100` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/quotations/inquire-daily-indexchartprice` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `https://openapivts.koreainvestment.com:29443`

> 국내주식 업종기간별시세(일/주/월/년) API입니다.
실전계좌/모의계좌의 경우, 한 번의 호출에 최대 50건까지 확인 가능합니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `FID_COND_MRKT_DIV_CODE` | 조건 시장 분류 코드 | string | Y | 업종 : U |
| `FID_INPUT_ISCD` | 업종 상세코드 | string | Y | '0001 : 종합; 0002 : 대형주; ...; 포탈 (FAQ : 종목정보 다운로드(국내) - 업종코드 참조)' |
| `FID_INPUT_DATE_1` | 조회 시작일자 | string | Y | 조회 시작일자 (ex. 20220501) |
| `FID_INPUT_DATE_2` | 조회 종료일자 | string | Y | 조회 종료일자 (ex. 20220530) |
| `FID_PERIOD_DIV_CODE` | '	기간분류코드' | string | Y | ' D:일봉 W:주봉, M:월봉, Y:년봉' |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 필수] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |
