# ELW 당일급변종목

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `ELW 당일급변종목` |
| API ID | `국내주식-171` |
| 실전 TR_ID | `FHPEW02870000` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/elw/v1/ranking/quick-change` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `모의투자 미지원`

> ELW 당일급변종목 API입니다. 
한국투자 HTS(eFriend Plus) &gt; [0287] ELW 당일급변종목 화면의 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `FID_COND_MRKT_DIV_CODE` | 조건시장분류코드 | string | Y | 시장구분코드 (W) |
| `FID_COND_SCR_DIV_CODE` | 조건화면분류코드 | string | Y | Unique key(20287) |
| `FID_UNAS_INPUT_ISCD` | 기초자산입력종목코드 | string | Y | '000000(전체), 2001(코스피200); , 3003(코스닥150), 005930(삼성전자) ' |
| `FID_INPUT_ISCD` | 발행사 | string | Y | '00000(전체), 00003(한국투자증권); , 00017(KB증권), 00005(미래에셋주식회사)' |
| `FID_MRKT_CLS_CODE` | 시장구분코드 | string | Y | Unique key(A) |
| `FID_INPUT_PRICE_1` | 가격(이상) | string | Y |  |
| `FID_INPUT_PRICE_2` | 가격(이하) | string | Y |  |
| `FID_INPUT_VOL_1` | 거래량(이상) | string | Y |  |
| `FID_INPUT_VOL_2` | 거래량(이하) | string | Y |  |
| `FID_HOUR_CLS_CODE` | 시간구분코드 | string | Y | 1(분), 2(일) |
| `FID_INPUT_HOUR_1` | 입력 일 또는 분 | string | Y |  |
| `FID_INPUT_HOUR_2` | 기준시간(분 선택 시) | string | Y |  |
| `FID_RANK_SORT_CLS_CODE` | 순위정렬구분코드 | string | Y | '1(가격급등), 2(가격급락), 3(거래량급증); , 4(매수잔량급증), 5(매도잔량급증)' |
| `FID_BLNG_CLS_CODE` | 결재방법 | string | Y | 0(전체), 1(일반), 2(조기종료) |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |
