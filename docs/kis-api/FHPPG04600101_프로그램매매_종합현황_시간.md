# 프로그램매매 종합현황(시간)

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `프로그램매매 종합현황(시간)` |
| API ID | `국내주식-114` |
| 실전 TR_ID | `FHPPG04600101` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/quotations/comp-program-trade-today` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `미지원`

> 프로그램매매 종합현황(시간) API입니다. 
한국투자 HTS(eFriend Plus) &gt; [0460] 프로그램매매 종합현황 화면의 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.

※ 장시간(09:00~15:30) 동안의 최근 30분간의 데이터 확인이 가능하며, 다음조회가 불가합니다.
※ 장시간(09:00~15:30) 이후에는 bsop_hour 에 153000 ~ 170000 까지의 시간데이터가 출력되지만 데이터는 모두 동일한 장마감 데이터인 점 유의 부탁드립니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `FID_COND_MRKT_DIV_CODE` | 시장 분류 코드 | string | Y | KRX : J , NXT : NX, 통합 : UN |
| `FID_MRKT_CLS_CODE` | 시장 구분 코드 | string | Y | K:코스피, Q:코스닥 |
| `FID_SCTN_CLS_CODE` | 구간 구분 코드 | string | Y | 공백 입력 |
| `FID_INPUT_ISCD` | 입력 종목코드 | string | Y | 공백 입력 |
| `FID_COND_MRKT_DIV_CODE1` | 시장 분류코드1 | string | Y | 공백 입력 |
| `FID_INPUT_HOUR_1` | 입력 시간1 | string | Y | 공백 입력 |
