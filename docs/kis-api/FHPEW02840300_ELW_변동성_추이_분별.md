# ELW 변동성 추이(분별)

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `ELW 변동성 추이(분별)` |
| API ID | `국내주식-179` |
| 실전 TR_ID | `FHPEW02840300` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/elw/v1/quotations/volatility-trend-minute` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `모의투자 미지원`

> ELW 변동성 추이(분별) API입니다. 
한국투자 HTS(eFriend Plus) &gt; [0284] ELW 변동성 추이 화면의 "분별" 변동성 추이 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `FID_COND_MRKT_DIV_CODE` | 조건시장분류코드 | string | Y | W(Unique key) |
| `FID_INPUT_ISCD` | 입력종목코드 | string | Y | ex) 58J297(KBJ297삼성전자콜) |
| `FID_HOUR_CLS_CODE` | 시간구분코드 | string | Y | '60(1분), 180(3분), 300(5분), 600(10분), 1800(30분), 3600(60분); ' |
| `FID_PW_DATA_INCU_YN` | 과거데이터 포함 여부 | string | Y | N(과거데이터포함X),Y(과거데이터포함O) |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |

## Response Body

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `rt_cd` | 성공 실패 여부 | string | Y |  |
| `msg_cd` | 응답코드 | string | Y |  |
| `msg1` | 응답메세지 | string | Y |  |
| `output` | 응답상세 | object array | Y | array |
| `stck_bsop_date` | 주식 영업 일자 | string | Y |  |
| `stck_cntg_hour` | 주식 체결 시간 | string | Y |  |
| `stck_prpr` | 주식 현재가 | string | Y |  |
| `elw_oprc` | ELW 시가2 | string | Y |  |
| `elw_hgpr` | ELW 최고가 | string | Y |  |
| `elw_lwpr` | ELW 최저가 | string | Y |  |
| `hts_ints_vltl` | HTS 내재 변동성 | string | Y |  |
| `hist_vltl` | 역사적 변동성 | string | Y |  |
