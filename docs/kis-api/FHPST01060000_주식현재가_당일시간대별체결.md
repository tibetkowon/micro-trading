# 주식현재가 당일시간대별체결

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `주식현재가 당일시간대별체결` |
| API ID | `v1_국내주식-023` |
| 실전 TR_ID | `FHPST01060000` |
| 모의 TR_ID | `FHPST01060000` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/quotations/inquire-time-itemconclusion` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `https://openapivts.koreainvestment.com:29443`

> 주식현재가 당일시간대별체결 API입니다. 

* FID_INPUT_HOUR_1 를 이용하여 과거시간대 체결데이터 확인 가능

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `FID_COND_MRKT_DIV_CODE` | 조건 시장 분류 코드 | string | Y | J:KRX, NX:NXT, UN:통합 |
| `FID_INPUT_ISCD` | 입력 종목코드 | string | Y | 종목코드 (ex 005930 삼성전자) |
| `FID_INPUT_HOUR_1` | 입력 시간1 | string | Y | 입력시간 |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |

## Response Body

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `rt_cd` | 성공 실패 여부 | string | Y |  |
| `msg_cd` | 응답코드 | string | Y |  |
| `msg1` | 응답메세지 | string | Y |  |
| `output1` | 응답상세 | object | Y | single |
| `stck_prpr` | 주식 현재가 | string | Y |  |
| `prdy_vrss` | 전일 대비 | string | Y |  |
| `prdy_vrss_sign` | 전일 대비 부호 | string | Y |  |
| `prdy_ctrt` | 전일 대비율 | string | Y |  |
| `acml_vol` | 누적 거래량 | string | Y |  |
| `prdy_vol` | 전일 거래량 | string | Y |  |
| `rprs_mrkt_kor_name` | 대표 시장 한글 명 | string | Y |  |
| `output2` | 응답상세 | object | Y | single |
| `stck_cntg_hour` | 주식 체결 시간 | string | Y |  |
| `stck_pbpr` | 주식 현재가 | string | Y |  |
| `prdy_vrss` | 전일 대비 | string | Y |  |
| `prdy_vrss_sign` | 전일 대비 부호 | string | Y |  |
| `prdy_ctrt` | 전일 대비율 | string | Y |  |
| `askp` | 매도호가 | string | Y |  |
| `bidp` | 매수호가 | string | Y |  |
| `tday_rltv` | 당일 체결강도 | string | Y |  |
| `acml_vol` | 누적 거래량 | string | Y |  |
| `cnqn` | 체결량 | string | Y |  |
