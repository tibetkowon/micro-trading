# 국내선물 영업일조회

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `국내선물 영업일조회` |
| API ID | `국내주식-160` |
| 실전 TR_ID | `HHMCM000002C0` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/quotations/market-time` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `미지원`

> 국내선물 영업일조회 API입니다.
한국투자 HTS(eFriend Plus) &gt; [1938] 시가총액순위 화면 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.
API호출 시 body 혹은 params로 입력하는 사항이 없습니다.

## Request Header

> 공통 헤더만 사용. [_공통헤더.md](_공통헤더.md) 참조

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `rt_cd` | 성공 실패 여부 | string | Y |  |
| `msg_cd` | 응답코드 | string | Y |  |
| `msg1` | 응답메세지 | string | Y |  |
| `output1` | 응답상세 | object array | Y | array |
| `date1` | 영업일1 | string | Y |  |
| `date2` | 영업일2 | string | Y |  |
| `date3` | 영업일3 | string | Y | 영업일 당일 |
| `date4` | 영업일4 | string | Y |  |
| `date5` | 영업일5 | string | Y |  |
| `today` | 오늘일자 | string | Y |  |
| `time` | 현재시간 | string | Y |  |
| `s_time` | 장시작시간 | string | Y |  |
| `e_time` | 장마감시간 | string | Y |  |
