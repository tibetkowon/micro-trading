# 금리 종합(국내채권_금리)

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `금리 종합(국내채권_금리)` |
| API ID | `국내주식-155` |
| 실전 TR_ID | `FHPST07020000` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/quotations/comp-interest` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `모의투자 미지원`

> 금리 종합(국내채권/금리) API입니다.
한국투자 HTS(eFriend Plus) &gt; [0702] 금리 종합 화면의 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.

※ 11:30 이후에 신규데이터가 수신되는 점 참고하시기 바랍니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `FID_COND_MRKT_DIV_CODE` | 조건시장분류코드 | string | Y | Unique key(I) |
| `FID_COND_SCR_DIV_CODE` | 조건화면분류코드 | string | Y | Unique key(20702) |
| `FID_DIV_CLS_CODE` | 분류구분코드 | string | Y | 1: 해외금리지표 |
| `FID_DIV_CLS_CODE1` | 분류구분코드 | string | Y | 공백 : 전체 |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |
