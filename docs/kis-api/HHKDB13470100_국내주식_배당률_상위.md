# 국내주식 배당률 상위

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `국내주식 배당률 상위` |
| API ID | `국내주식-106` |
| 실전 TR_ID | `HHKDB13470100` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/ranking/dividend-rate` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `모의투자 미지원`

> 국내주식 배당률 상위 API입니다. 
한국투자 HTS(eFriend Plus) &gt; [0188] 배당률 상위 화면의 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.
최대 30건 확인 가능하며, 다음 조회가 불가합니다.

※ 30건 이상의 목록 조회가 필요한 경우, 대안으로 종목조건검색 API를 이용해서 원하는 종목 100개까지 검색할 수 있는 기능을 제공하고 있습니다.
종목조건검색 API는 HTS(efriend Plus) [0110] 조건검색에서 등록 및 서버저장한 나의 조건 목록을 확인할 수 있는 API로,
자세한 사용 방법은 공지사항 - [조건검색 필독] 조건검색 API 이용안내 참고 부탁드립니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `CTS_AREA` | CTS_AREA | string | Y | 공백 |
| `GB1` | KOSPI | string | Y | 0:전체, 1:코스피, 2: 코스피200, 3: 코스닥, |
| `UPJONG` | 업종구분 | string | Y | '코스피(0001:종합, 0002:대형주.…0027:제조업 ), ; 코스닥(1001:종합, …. 1041:IT부품; 코스피200 (2001:KOSPI200, 2007:KOSPI100, 2008:KOSPI50)' |
| `GB2` | 종목선택 | string | Y | 0:전체, 6:보통주, 7:우선주 |
| `GB3` | 배당구분 | string | Y | 1:주식배당, 2: 현금배당 |
| `F_DT` | 기준일From | string | Y |  |
| `T_DT` | 기준일To | string | Y |  |
| `GB4` | 결산/중간배당 | string | Y | 0:전체, 1:결산배당, 2:중간배당 |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |

## Response Body

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `rt_cd` | 성공 실패 여부 | string | Y |  |
| `msg_cd` | 응답코드 | string | Y |  |
| `msg1` | 응답메세지 | string | Y |  |
| `output1` | 응답상세 | object array | Y | array |
| `rank` | 순위 | string | Y |  |
| `sht_cd` | 종목코드 | string | Y |  |
| `isin_name` | 종목명 | string | Y |  |
| `record_date` | 기준일 | string | Y |  |
| `per_sto_divi_amt` | 현금/주식배당금 | string | Y |  |
| `divi_rate` | 현금/주식배당률(%) | string | Y |  |
| `divi_kind` | 배당종류 | string | Y |  |
