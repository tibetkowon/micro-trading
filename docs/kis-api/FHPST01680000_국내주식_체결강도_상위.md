# 국내주식 체결강도 상위

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `국내주식 체결강도 상위` |
| API ID | `v1_국내주식-101` |
| 실전 TR_ID | `FHPST01680000` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/ranking/volume-power` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `모의투자 미지원`

> 국내주식 체결강도 상위 API입니다.
한국투자 HTS(eFriend Plus) &gt; [0168] 체결강도 상위 화면의 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.
최대 30건 확인 가능하며, 다음 조회가 불가합니다.

※ 30건 이상의 목록 조회가 필요한 경우, 대안으로 종목조건검색 API를 이용해서 원하는 종목 100개까지 검색할 수 있는 기능을 제공하고 있습니다.
종목조건검색 API는 HTS(efriend Plus) [0110] 조건검색에서 등록 및 서버저장한 나의 조건 목록을 확인할 수 있는 API로,
자세한 사용 방법은 공지사항 - [조건검색 필독] 조건검색 API 이용안내 참고 부탁드립니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `fid_trgt_exls_cls_code` | 대상 제외 구분 코드 | string | Y | 0 : 전체 |
| `fid_cond_mrkt_div_code` | 조건 시장 분류 코드 | string | Y | 시장구분코드 (J:KRX, NX:NXT) |
| `fid_cond_scr_div_code` | 조건 화면 분류 코드 | string | Y | Unique key( 20168 ) |
| `fid_input_iscd` | 입력 종목코드 | string | Y | 0000:전체, 0001:거래소, 1001:코스닥, 2001:코스피200 |
| `fid_div_cls_code` | 분류 구분 코드 | string | Y | 0: 전체, 1: 보통주 2: 우선주 |
| `fid_input_price_1` | 입력 가격1 | string | Y | 입력값 없을때 전체 (가격 ~) |
| `fid_input_price_2` | 입력 가격2 | string | Y | 입력값 없을때 전체 (~ 가격) |
| `fid_vol_cnt` | 거래량 수 | string | Y | 입력값 없을때 전체 (거래량 ~) |
| `fid_trgt_cls_code` | 대상 구분 코드 | string | Y | 0 : 전체 |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |

## Response Body

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `rt_cd` | 성공 실패 여부 | string | Y |  |
| `msg_cd` | 응답코드 | string | Y |  |

| `output` | 응답상세 | object array | Y | array |

| `hts_kor_isnm` | HTS 한글 종목명 | string | Y |  |
| `stck_prpr` | 주식 현재가 | string | Y |  |
| `prdy_vrss` | 전일 대비 | string | Y |  |
| `prdy_vrss_sign` | 전일 대비 부호 | string | Y |  |
| `prdy_ctrt` | 전일 대비율 | string | Y |  |

| `shnu_cnqn_smtn` | 매수2 체결량 합계 | string | Y |  |
