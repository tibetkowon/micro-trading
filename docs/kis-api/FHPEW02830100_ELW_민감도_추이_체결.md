|------|---|
| 통신방식 | `REST` |
| API 명 | `ELW 민감도 추이(체결)` |
| API ID | `국내주식-175` |
| 실전 TR_ID | `FHPEW02830100` |
| 모의 TR_ID | `모의투자 미지원` |

한국투자 HTS(eFriend Plus) &gt; [0283] ELW 민감도 추이 화면 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.
