# ELW 거래량순위

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `ELW 거래량순위` |
| API ID | `국내주식-168` |
| 실전 TR_ID | `FHPEW02780000` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/elw/v1/ranking/volume-rank` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `모의투자 미지원`

> ELW 거래량순위 API입니다. 
한국투자 HTS(eFriend Plus) &gt; [0278] ELW 거래량순위 화면의 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `FID_COND_MRKT_DIV_CODE` | 조건시장분류코드 | string | Y | W |
| `FID_COND_SCR_DIV_CODE` | 조건화면분류코드 | string | Y | 20278 |
| `FID_UNAS_INPUT_ISCD` | 기초자산입력종목코드 | string | Y | 000000 |
| `FID_INPUT_ISCD` | 발행사 | string | Y | 00000(전체), 00003(한국투자증권); , 00017(KB증권), 00005(미래에셋주식회사)' |
| `FID_INPUT_RMNN_DYNU_1` | 입력잔존일수 | string | Y |  |
| `FID_DIV_CLS_CODE` | 콜풋구분코드 | string | Y | 0(전체), 1(콜), 2(풋) |
| `FID_INPUT_PRICE_1` | 가격(이상) | string | Y | 거래가격1(이상) |
| `FID_INPUT_PRICE_2` | 가격(이하) | string | Y | 거래가격1(이하) |
| `FID_INPUT_VOL_1` | 거래량(이상) | string | Y | 거래량1(이상) |
| `FID_INPUT_VOL_2` | 거래량(이하) | string | Y | 거래량1(이하) |
| `FID_INPUT_DATE_1` | 조회기준일 | string | Y | 입력날짜(기준가 조회기준) |
| `FID_RANK_SORT_CLS_CODE` | 순위정렬구분코드 | string | Y | 0: 거래량순 1: 평균거래증가율 2: 평균거래회전율 3:거래금액순 4: 순매수잔량순 5: 순매도잔량순 |
| `FID_BLNG_CLS_CODE` | 소속구분코드 | string | Y | 0: 전체 |
| `FID_INPUT_ISCD_2` | LP발행사 | string | Y | 0000 |
| `FID_INPUT_DATE_2` | 만기일-최종거래일조회 | string | Y | 공백 |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |
