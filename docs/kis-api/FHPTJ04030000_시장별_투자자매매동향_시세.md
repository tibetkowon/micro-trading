| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `시장별 투자자매매동향(시세)` |
| API ID | `v1_국내주식-074` |
| 실전 TR_ID | `FHPTJ04030000` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/quotations/inquire-investor-time-by-market` |

- 모의: `모의투자 미지원`

> 시장별 투자자매매동향(시세성) API입니다.
