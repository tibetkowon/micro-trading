# [국내주식] 실시간 WebSocket API 명세

> **WebSocket URL**: `ws://ops.koreainvestment.com:21000` (실전) / `ws://ops.koreainvestment.com:31000` (모의)
> **Approval Key**: `POST /oauth2/Approval` — body: `grant_type`, `appkey`, `secretkey` (appkey/appsecret 아님)

---

## WebSocket 공통 메시지 구조

### 구독 요청

```json
{
  "header": {
    "approval_key": "{approval_key}",
    "custtype": "P",
    "tr_type": "1",
    "content-type": "utf-8"
  },
  "body": {
    "input": {
      "tr_id": "{TR_ID}",
      "tr_key": "{tr_key}"
    }
  }
}
```

- `tr_type`: `"1"` = 등록, `"2"` = 해제

### 응답 포맷 (데이터)

```
encFlag|trID|count|data
```

- 파이프(`|`) 구분
- 데이터는 `^` 구분 (필드 배열)

## 2. 국내주식 실시간체결통보

- **TR_ID**: `H0STCNI0` (실전) / `H0STCNI9` (모의)
- **tr_key**: **HTS ID** (`KIS_HTS_ID` 환경변수)

> **암호화**: 체결통보는 AES-256-CBC + PKCS7 암호화됨.
> 구독 성공 JSON의 `body.output.key` / `.iv` 를 사용하여 복호화.

### 데이터 필드 (^ 구분, 복호화 후)

| Index | 필드명 | 설명 |
|-------|--------|------|
| [2] | ODER_NO | **주문번호** |
| [4] | SELN_BYOV_CLS | 매도매수구분 (`01`:매도, `02`:매수) |
| [8] | STCK_SHRN_ISCD | 단축종목코드 |
| [9] | CNTG_QTY | **체결수량** |
| [10] | CNTG_UNPR | **체결단가** |
| [13] | CNTG_YN | **체결여부 (`2`=체결)** |
| [14] | RFUS_YN | 거부여부 (`0`:정상) |

## 3. 국내주식 실시간호가 (KRX)

- **TR_ID**: `H0STASP0` (실전/모의 공통)
- **tr_key**: 종목코드 (6자리)

### 데이터 필드 (^ 구분, 주요)

| Index | 필드명 | 설명 |
|-------|--------|------|

| [3] | ASKP1~5 | 매도호가 1~5단계 |
| [13] | BIDP1~5 | 매수호가 1~5단계 |
| [23] | ASKP_RSQN1~5 | 매도호가잔량 1~5단계 |
| [33] | BIDP_RSQN1~5 | 매수호가잔량 1~5단계 |

## 구현 주의사항

- **구독 성공 응답**: JSON 형태 (`{"header":{"tr_id":"H0STCNT0","tr_key":"005930",...},"body":{"rt_cd":"0",...}}`)
- **데이터 응답**: 파이프 구분 텍스트 형태 (JSON 아님)
- **재연결**: `intentionalStop` 플래그로 계획된 종료(16:00 disconnect)와 에러 재연결 구분 필요
- **체결통보 AES 키**: 종목별 구독이 아닌 계좌 단위. HTS ID로 한 번만 구독.
