## 1. 거래량순위 (HHDFS76310010)

- **Method/URL**: `GET /uapi/overseas-stock/v1/ranking/trade-vol`

### 요청 Query

| Element | Required | 설명 |
|---------|----------|------|
| KEYB | Y | 공백 |
| AUTH | Y | 공백 |
| EXCD | Y | 거래소코드 — `NYS`/`NAS`/`AMS`/`HKS`/`SHS`/`SZS` |
| NDAY | Y | `0`:당일, `1`:2일, `3`:5일, `4`:10일, `5`:20일 |
| PRC1 | N | 최소가격 (USD) |
| PRC2 | N | 최대가격 (USD) |
| VOL_RANG | Y | `0`:전체, `1`:100주↑, `2`:1000주↑, `3`:10000주↑ |

### 응답 (output2 — 순위 배열)

| Element | 설명 |
|---------|------|
| rsym | 실시간종목코드 (예: `DNASAAPL`) |
| excd | 거래소코드 |
| symb | 종목코드 |
| name | 종목명(한글) |
| ename | 종목명(영문) |
| last | 현재가 |
| rate | 등락율 |
| tvol | 거래량 |
| rank | 순위 |

## 구현 주의사항

- **AND/OR 조건**: 미장 순위 API는 각 타입이 별개 단일 호출 → 국내의 교집합(AND) 로직과 다름.
  미장은 각 타입 결과를 합산(OR 방식 고정)하거나 단일 타입만 사용하는 방식으로 단순화.
- **EXCD vs OVRS_EXCG_CD**: 시세/WebSocket은 `NAS`/`NYS`, 주문은 `NASD`/`NYSE` (참고: 거래소 코드 대응표)
- **`rsym` 형식**: `D` + 거래소3자리 + 종목코드 (예: `DNASAAPL`) — WebSocket tr_key와 동일
