# 주식당일분봉조회

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `주식당일분봉조회` |
| API ID | `v1_국내주식-022` |
| 실전 TR_ID | `FHKST03010200` |
| 모의 TR_ID | `FHKST03010200` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/quotations/inquire-time-itemchartprice` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `https://openapivts.koreainvestment.com:29443`

> 주식당일분봉조회 API입니다. 
실전계좌/모의계좌의 경우, 한 번의 호출에 최대 30건까지 확인 가능합니다.

※ 당일 분봉 데이터만 제공됩니다. (전일자 분봉 미제공)

※ input &gt; FID_INPUT_HOUR_1 에 미래일시 입력 시에 현재가로 조회됩니다.
ex) 오전 10시에 113000 입력 시에 오전 10시~11시30분 사이의 데이터가 오전 10시 값으로 조회됨

※ output2의 첫번째 배열의 체결량(cntg_vol)은 첫체결이 발생되기 전까지는 이전 분봉의 체결량이 해당 위치에 표시됩니다. 
해당 분봉의 첫 체결이 발생되면 해당 이전분 체결량이 두번째 배열로 이동되면서 새로운 체결량으로 업데이트됩니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `FID_COND_MRKT_DIV_CODE` | 조건 시장 분류 코드 | string | Y | J:KRX, NX:NXT, UN:통합 |
| `FID_INPUT_ISCD` | 입력 종목코드 | string | Y | 종목코드 (ex 005930 삼성전자) |
| `FID_INPUT_HOUR_1` | 입력 시간1 | string | Y | 입력시간 |
| `FID_PW_DATA_INCU_YN` | 과거 데이터 포함 여부 | string | Y |  |
| `FID_ETC_CLS_CODE` | 기타 구분 코드 | string | Y |  |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |
