# 프로그램매매 투자자매매동향(당일)

| 항목 | 값 |
|------|---|
| 통신방식 | `REST` |
| API 명 | `프로그램매매 투자자매매동향(당일)` |
| API ID | `국내주식-116` |
| 실전 TR_ID | `HHPPG046600C1` |
| 모의 TR_ID | `모의투자 미지원` |
| Method | `GET` |
| URL | `/uapi/domestic-stock/v1/quotations/investor-program-trade-today` |

- 실전: `https://openapi.koreainvestment.com:9443`
- 모의: `미지원`

> 프로그램매매 투자자매매동향(당일) API입니다.
한국투자 HTS(eFriend Plus) &gt; [0466] 프로그램매매 투자자별 동향 화면 의 "당일동향" 표의 기능을 API로 개발한 사항으로, 해당 화면을 참고하시면 기능을 이해하기 쉽습니다.

## Request Header

> 공통 헤더는 [_공통헤더.md](_공통헤더.md) 참조

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `EXCH_DIV_CLS_CODE` | 거래소 구분 코드 | string | Y | J : KRX, NX : NXT, UN : 통합 |
| `MRKT_DIV_CLS_CODE` | 시장 구분 코드 | string | Y | 1:코스피, 4:코스닥 |

## Response Header

| Element | 한글명 | Type | Required | Description |
|---------|--------|------|----------|-------------|
| `content-type` | 컨텐츠타입 | string | Y | application/json; charset=utf-8 |
| `tr_id` | 거래ID | string | Y | 요청한 tr_id |
| `tr_cont` | 연속 거래 여부 | string | N | tr_cont를 이용한 다음조회 불가 API |
| `gt_uid` | Global UID | string | N | [법인 전용] 거래고유번호로 사용하므로 거래별로 UNIQUE해야 함 |
